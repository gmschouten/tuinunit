# De Tuinunit

Ontwerpstudie voor een tuinunit van Douglas-hout: schuur, poort en veranda in één lijn achter het zwembad, met een glazen kinderhek.

- `index.html`: presentatie van het ontwerp
- `3d.html`: zelf door het 3D-model lopen (three.js)
- `model/`: het model (glTF) en de standpunten

Model en renders gemaakt in Blender (Cycles). Planten deels van Poly Haven (CC0). Sfeerbeelden gemaakt met AI.
